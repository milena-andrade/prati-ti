# PraTI — site institucional demonstrativo

Site estático, responsivo, com HTML, CSS e JavaScript puro. Não exige instalação nem backend.

## Publicar no GitHub Pages
1. Crie um repositório público chamado `prati-ti.github.io` na conta GitHub `prati-ti`, caso o nome esteja disponível. Se usar outra conta, o endereço será diferente.
2. Envie `index.html`, `styles.css` e `script.js` para a raiz do repositório.
3. Acesse **Settings → Pages → Build and deployment → Deploy from a branch**. Selecione `main` e `/ (root)` e salve.
4. Aguarde a publicação e abra o endereço indicado pelo GitHub Pages.

## Antes de usar comercialmente
- Substitua `contato@exemplo.com` no HTML por um endereço oficial e remova o bloqueio demonstrativo no `script.js`.
- Confirme os preços, condições dos planos e disponibilidade da sede.
- O endereço `https://prati-ti.github.io` é apenas uma proposta e não foi registrado.
- Se desejar um formulário funcional, será necessário integrar um serviço de formulários ou backend.
